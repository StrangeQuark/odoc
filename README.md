# Odoc (temporary repository name)

`Odoc` is only the current repository locator, not an approved public project or product
name. The [collision and replacement-name research](docs/project/name-collision-research.md)
recommends rejecting it. The owner must select a replacement candidate and complete an
expanded availability and appropriate qualified review before separately approving that
candidate for public use; no candidate has been selected or cleared.

The documentation platform being planned will provide polished, searchable,
permission-aware documentation and first-class GitHub repository, README, and static
Java API documentation. The outbound license proposal below is not effective until a
root `LICENSE` is approved and added.

The project is currently in its foundation phase. Application code and supported
build commands will be added by the Phase 0 bootstrap packages; this README does
not claim that an application is runnable yet.
